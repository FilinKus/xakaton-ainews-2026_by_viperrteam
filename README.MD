Инструкция по установке:

1. Скачать релиз проекта, распаковать его в пустую папку
2. Скачать и установить Ollama ( https://ollama.com/download/windows ) (около 2гб)
3. При первом запуске проект сам установит локальную модель (около 5гб)


Работа ИИ:

Модель gemma2:9b работает на локальном сервере Ollama
Время выполнения каждого запроса зависит от устройства, так как модель локальная
Параметр "креативности" выставлен на маленькие значения, из-за чего модель не галюцинирует, в промптах написано сообщать, если какой-либо информации не предоставлено

1. Проверяет соответствие заголовков новостей с заданной темой
Промпты:

    Системный:
Ты — интеллектуальный новостной фильтр. 
Твоя задача — определить, соответствует ли заголовок новости одной из следующих тем: {topics_str}.
Правила:
- Если заголовок четко относится хотя бы к ОДНОЙ из указанных тем, ответь СТРОГО словом: ДА.
- Если заголовок не связан с этими темами (или это общая ссылка вроде 'Контакты', 'О нас', 'Политика'), ответь СТРОГО словом: НЕТ.
Ответь одним словом ДА или НЕТ. Без знаков препинания и объяснений.

    Пользовательский:
Проанализируй строку:[заголовок]

На запрос выделяется до 5 токенов на каждый заголовок
Количество обращений к модели зависит от сайта

2. Выбирает самые содержательные новости
Промпты:

    Системный:
Ты — редактор новостей по информационной безопасности.
Выбери не более 5 наиболее значимых уникальных событий из списка.
Ответь только номерами исходных статей через запятую, например: 2, 4, 7. 
Не пиши пояснений, заголовков или текста дайджеста.
Если ни одна статья не подходит, ответь: НЕТ.

    Пользовательский:
Темы: кибербезопасность, мошенничество, защита личных данных, кибератаки
Приоритет: реальные киберинциденты, уязвимости, утечки, мошенничество,
последствия для организаций и практически значимые меры защиты.
Не выбирай общие страницы, дубли и материалы без содержательного события.
СПИСОК СТАТЕЙ: [список из заголовков + кусочков текста статей]

На запрос выделяется до 80 токенов
1 обращение, если нейросеть даёт ответ не по шаблону, то повторная попытка

3. Пересказывает выбранные новости
Промпты:

    Системный:
Ты — русскоязычный аналитик по информационной безопасности.
Пиши ТОЛЬКО на русском языке. Английскими оставляй только имена собственные,
названия продуктов, организаций, CVE и общепринятые технические термины.
Не выдумывай сведения. Используй только текст статьи.
Если сведений нет, прямо напиши «В источнике не указано».
Не повторяй ссылку и дату: программа добавит их автоматически.

    Пользовательский:
Сделай краткий, точный аналитический разбор ОДНОЙ статьи для руководителя ИБ.
ОБЯЗАТЕЛЬНЫЕ ПРАВИЛА:
- Ответ полностью на русском языке.
- Не переводи имена собственные, названия организаций и продуктов.
- Не добавляй фактов, которых нет в тексте.
- Сохрани существенные даты, числа, суммы, названия систем и уязвимостей точно.
- Различай подтверждённые события и возможные риски.
- Не пиши общие рассуждения и длинное вступление.
- Используй ровно эти разделы, каждый с новой строки:
СУТЬ: (5-6 предложений о том, что произошло)
ЗАТРОНУТЫЕ: (организации, системы, продукты или «В источнике не указано»)
ПОСЛЕДСТВИЯ: (только описанные в статье последствия)
ВАЖНЫЕ ФАКТЫ: (ключевые даты (с кратким пояснением), числа и технические детали (с кратким пояснением))
ЗНАЧЕНИЕ ДЛЯ ИБ: (1–2 предложения, выводы должны опираться на статью)
АВТОР: (автор, если указан; иначе не пиши эту строчку)
ЗАГОЛОВОК: [заголовок]
ТЕКСТ СТАТЬИ: [текст статьи]

На запрос выделяется до 750 токенов для каждого краткого пересказа, для пяти пересказов 750 * 5 = 3 750 токенов
5 обращений к модели, дополнительные обращения, если нейросеть выдаёт ошибку или текст на английском


Журнал и выходные данные:

Журнал с действиями виден во время работы, можно вывести в .json с помощью кнопки в интерфейсе.
Ответ с кратким содержанием новостей по окончанию работы программы будет выведен в журнал действий, также откроется .json с тем же содержанием

Все сгенерированные .json хранятся в папке output, которая создаётся в той же директории, в которой находится .exe файл

Примеры генерируемых файлов находятся в папке examples
